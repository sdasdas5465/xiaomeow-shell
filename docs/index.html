安装与更新

  • 解压到纯英文路径的普通文件夹（例如 D:\tlbb\）， 不要放 Program Files，也不要直接放在桌面。
  • 双击 xiaomeow-shell.exe。首次运行 Windows SmartScreen 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」。
  • 已装过 v1.6.37 或更新 的版本，不用重复下载：软件里 「设置 → 软件更新 → 检查更新」，一次只下几 MB 的差量包。
还在 v1.6.36 或更早？请先手动装一次本页的完整包。
那些版本的更新器有缺陷：替换文件时会被它自己加载的 DLL 卡住 （_internal\ucrtbase.dll 报「另一个程序正在使用此文件」）， 于是在线更新会一直显示「有新版本」，点下去、重启，版本号纹丝不动。 这不是网络问题，重试多少次都一样。
手动装一次本页完整包就能上岸 —— 装上之后的版本更新器已经修好， 往后的更新都走差量包，不用再手动下载。
